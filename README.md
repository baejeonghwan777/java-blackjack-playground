## 블랙잭 게임

* 구현할 기능 목록

1. 사용자 이름, 배팅금을 입력받아서 플레이어 객체 생성
2. 블랙잭을 시작하기 위한 드로우 기능 구현 - 딜러, 플레이어 모두 2장을 뽑지만
딜러는 카드 한장만 공개, 플레이어는 카드 두장을 공개한다는 차이점을 두어야 함.
3. 블랙잭 규칙 1 - 숫자가 21을 넘지 않는 한 플레이어는 카드를 뽑는 행위를 할 지 말지 선택할 수 있다. 이때 카드를 뽑지 않고 넘어가면 stay, 그렇지 않고 카드를 뽑는 행위를 하는 것을 hit이라고 한다.
4. 블랙잭 규칙 2 - 숫자가 21을 넘어버리면 burst 상태가 되며 이 경우에는 숫자가 아무리 높더라도 무조건 패배하게 된다.
5. 블랙잭 규칙 3 - 첫 턴에 A, 10점짜리 카드(K, Q, J, 10)를 동시에 뽑으면 블랙잭 상태가 되며 일반 21점보다 높은 점수가 되고
원래 걸었던 배팅금의 1.5배를 돌려받게 된다.
6. 딜러는 플레이어가 카드를 뽑을지 말지 선택한 후 카드의 합이 16이 넘어갈때까지 무한정 드로우를 진행한다.
7. 승리 조건 구현 : 딜러보다 점수가 높거나 딜러가 burst한 경우
8. 무승부 조건 구현 : 딜러랑 점수가 같은 경우
9. 패배 조건 구현 : 딜러보다 점수가 낮거나 플레이어가 burst한 경우
10. 플레이어의 경우 승리할 경우 배팅 금액을 가져가며, 패배할 경우 배팅 금액을 잃는다, 블랙잭일 경우에는 배팅 금액의 1.5배를 돌려받는다.
11. 딜러의 경우 플레이어들이 패배해서 금액을 잃는 만큼 수익이 생기며 플레이어들이 승리할 경우 플레이어들에게 금액을 지불해야 한다.
